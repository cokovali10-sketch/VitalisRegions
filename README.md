# VitalisRegions

Лёгкие регионы для Paper/Purpur 1.21.11. Выбор точек, создание, GUI владельцев и игроков с кнопками +/-, флаги, защита территории.

## Команды

Главная команда — `/area`, без аргументов показывает помощь. Алиасы: `/region`, `/regions`, `/rg` (старая команда тоже работает). Старые права `rg.*` тоже принимаются.

- `/area pos1` — точка 1 там, где стоишь
- `/area pos2` — точка 2 там, где стоишь
- `/area wand` — выдать золотой топор-жезл (ЛКМ — точка 1, ПКМ — точка 2). Деревянный топор не трогаем, чтобы не конфликтовать с WorldEdit
- `/area create <имя> [vert]` — создать регион (имя 3-16 символов: латиница, цифры, _/-). Параметр `vert` растягивает регион от bedrock до неба автоматически
- `/area delete <имя>` — удалить, повторить дважды за 15 секунд
- `/area list` — твои регионы, каждая строка кликабельна (клик — открыть окно)
- `/area info <имя>` — окно управления: владельцы и игроки кнопками +/-, флаги, удаление

Почти всё управление — мышкой: помощь `/area` со вставкой команд по клику, в списке клик открывает регион, после создания кнопка «открыть» ведёт в настройку.

Права: `area.use` и `area.create` (у всех), `area.unlimited` (обход лимитов), `area.bypass` (игнор защиты), `area.admin` (удаление чужих) — у операторов.

## Окно региона

- Книга по центру: мир, размер, углы, владелец
- Ряд владельцев: зелёная «+ Добавить», головы владельцев, красная «− Убрать». Ник вводится прямо в чат после клика
- Ряд игроков: так же через +/-
- Нижний ряд тумблеров (зелёный ВКЛ / красный ВЫКЛ): огонь, PVP, взрывы, механизмы, хомы. Дальше красная кнопка удаления (двойной клик), барьер «Закрыть»
- Создателя из владельцев убрать нельзя
- Участники могут открывать окно в режиме просмотра
- Переливающийся градиентный заголовок окна и префикс (MiniMessage: `<gradient:#5DFF6E:#00E5FF>текст</gradient>`, `<rainbow>`, цвета типа `<gray>` — свободно мешаются с кодами `&`)

## Защита

Чужим в регионе запрещено: ломать и ставить блоки, вёдра, открывать сундуки/двери/кнопки/верстаки и остальное интерактивное. Поршни не переносят блоки через границу. Огонь не поджигает и не расползается внутрь, лава и вода не затекают, эндермены не воруют блоки. Рамки и стойки на чужих стенах не вешаются, жемчуг и хорус внутрь не телепортируют. PVP и взрывы (без кратера и урона) — по флагам региона, по умолчанию выключены. Операторы и `area.bypass` проходят везде. Ники владельцев и игроков обновляются сами при входе. Админам доступна команда `/area reload` (перезагрузка конфига без рестарта).

Лимиты: 100 регионов на игрока, ограничений по высоте и ширине нет, пересечения запрещены. Создание бесплатное (в конфиге есть `economy.claim-price`, по умолчанию 0). Без Vault плагин работает как обычно.

Хранение: `plugins/VitalisRegions/regions.yml`, сейв при выключении. Поиск региона идёт по индексу мира — защита не лагает даже при сотнях регионов.

## Тесты

16 юнит-тестов (геометрия регионов, тексты): `.\gradlew.bat test`.

## Зависимости

- Ничего обязательного нет
- По желанию: Vault + экономика (цена создания), Essentials, WorldGuard (мирно сосуществуем, защиты складываются)

## Установка

1. Положить `VitalisRegions-X.X.X.jar` в `plugins/`
2. Перезапустить сервер
3. В консоли: `VitalisRegions enabled, regions: 0`
4. В игре: `/area wand`, выделить, `/area create home`, настроить через `/area info home`

## Сборка

```bat
.\gradlew.bat build --no-daemon
```

Нужны Java 21, Paper API `1.21.11-R0.1-SNAPSHOT`, VaultAPI (подтянутся сами).
