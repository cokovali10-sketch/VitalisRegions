# VitalisRegions

Лёгкие регионы для Paper/Purpur 1.21.11. Выбор точек, создание, GUI владельцев и игроков с кнопками +/-, флаги, защита территории.

## Команды

Главная команда — `/rg`, без аргументов показывает помощь. Алиасы: `/region`, `/regions`.

- `/rg pos1` — точка 1 там, где стоишь
- `/rg pos2` — точка 2 там, где стоишь
- `/rg wand` — выдать золотой топор-жезл (ЛКМ — точка 1, ПКМ — точка 2). Деревянный топор не трогаем, чтобы не конфликтовать с WorldEdit
- `/rg create <имя>` — создать регион (имя 3-16 символов: латиница, цифры, _/-)
- `/rg delete <имя>` — удалить, повторить дважды за 15 секунд
- `/rg list` — твои регионы с размерами
- `/rg info <имя>` — окно управления: владельцы и игроки кнопками +/-, флаги, удаление

Права: `rg.use` и `rg.create` (у всех), `rg.unlimited` (обход лимитов), `rg.bypass` (игнор защиты), `rg.admin` (удаление чужих) — у операторов.

## Окно региона

- Книга по центру: мир, размер, углы, владелец
- Ряд владельцев: зелёная «+ Добавить», головы владельцев, красная «− Убрать». Ник вводится прямо в чат после клика
- Ряд игроков: так же через +/-
- Нижний ряд: переключатели PVP и взрывов, красная кнопка удаления (двойной клик), барьер «Закрыть»
- Создателя из владельцев убрать нельзя

## Защита

Чужим в регионе запрещено: ломать и ставить блоки, вёдра, открывать сундуки/двери/кнопки/верстаки и остальное интерактивное. PVP и взрывы — по флагам региона (по умолчанию выключены). Операторы и `rg.bypass` проходят везде.

Лимиты: 5 регионов на игрока, сторона до 200 блоков, пересечения запрещены. Создание можно сделать платным через Vault (`economy.claim-price`, по умолчанию 0 — бесплатно). Без Vault плагин работает, просто бесплатно.

Хранение: `plugins/VitalisRegions/regions.yml`, сейв при выключении.

## Зависимости

- Ничего обязательного нет
- По желанию: Vault + экономика (цена создания), Essentials, WorldGuard (мирно сосуществуем, защиты складываются)

## Установка

1. Положить `VitalisRegions-X.X.X.jar` в `plugins/`
2. Перезапустить сервер
3. В консоли: `VitalisRegions enabled, regions: 0`
4. В игре: `/rg wand`, выделить, `/rg create home`, настроить через `/rg info home`

## Сборка

```bat
.\gradlew.bat build --no-daemon
```

Нужны Java 21, Paper API `1.21.11-R0.1-SNAPSHOT`, VaultAPI (подтянутся сами).
