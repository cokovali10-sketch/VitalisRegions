# VitalisRegions

Лёгкие регионы для Paper/Purpur 1.21.11 в стиле Heaven. Имён регионов нет — всё работает по месту где стоишь. Всё управление — кнопками в чате, окон нет. Рядом с владельцами и игроками кнопки [+] и [−]: жмёшь плюс — в строке чата появляется команда, дописываешь ник (TAB подсказывает), жмёшь минус — так же. После выделения точек чат спрашивает: приватить на всю высоту или как выделил.

## Команды (всего 3)

Главная команда — `/area`: если стоишь в своём регионе — покажет его, если в чужом — информации не даст, если в поле — покажет твои регионы. Алиасы: `/region`, `/regions`, `/rg`.

- `/area pos1` — точка 1 там, где стоишь
- `/area pos2` — точка 2 там, где стоишь
- `/area remove` — удалить регион под ногами (повторить дважды)
- `/area help` — самая простая инструкция в 5 строк

Всё остальное — кнопки в чате: создать регион (на всю высоту или как выделил), добавить/убрать владельцев и игроков, флаги, растянуть на всю высоту, удаление с кнопками Да/Отмена. Окон-инвентарей нет вообще. Меню в рамках Heaven-стиля.

Права: `area.use` и `area.create` (у всех), `area.unlimited` (обход лимитов), `area.bypass` (игнор защиты), `area.admin` (удаление чужих, reload) — у операторов. Старые права `rg.*` тоже принимаются.

## Окно региона

- Шапка: градиентное название, мир, размер, владелец
- ★ строка владельцев (жёлтые ники): [+] открывает окно ввода ника, [-] открывает окно со списком на выбор. Закрыл окно — ничего не происходит
- ● строка игроков (белые ники): так же через [+] и [-]
- Ввод ника работает и для оффлайн-игроков (лишь бы хоть раз заходили). Ошибка в нике — чат сразу скажет
- ◆ строка флагов-тумблеров (зелёный ВКЛ / красный ВЫКЛ): огонь, взрывы, механизмы, хомы — клик переключает. Флаги только для чужих, своим можно всё всегда
- Значки ★ ● ◆ из стандартного шрифта — видны всем, у каждого подсказка при наведении. Слова не сливаются: у каждой строки свой цвет
- Кнопки высоты, переименования и удаления (с Да/Отмена). Телепорта и PVP-флага нет
- Создателя из владельцев убрать нельзя
- Участники видят меню, менять ничего не могут
- Переливающиеся градиентные заголовки (MiniMessage: `<gradient:#5DFF6E:#00E5FF>текст</gradient>`, `<rainbow>`, цвета типа `<gray>` — свободно мешаются с кодами `&`)

## Защита

Своим (владельцы и участники) можно всё всегда, запреты только для чужих. Чужим запрещено: ломать и ставить блоки, вёдра, сундуки и верстаки всегда. Кнопки, рычаги, двери, люки, калитки, колокола — только если включён флаг механизмов (зелёный). Поршни не переносят блоки через границу. Огонь не поджигает и не расползается внутрь, лава и вода не затекают, эндермены не воруют блоки. Рамки и стойки на чужих стенах не вешаются, жемчуг и хорус внутрь не телепортируют. Взрывы без кратера и урона — по флагу (выключены по умолчанию), PVP обычное ванильное. Операторы и `area.bypass` проходят везде. Ники владельцев и игроков обновляются сами при входе. Админам доступна команда `/area reload` (перезагрузка конфига без рестарта).

Лимиты: 100 регионов на игрока, ограничений по высоте и ширине нет. Регионы не перекрываются: попытка создать внутри чужого или задеть край — сообщение «Тут уже есть регион». Создание бесплатное (в конфиге есть `economy.claim-price`, по умолчанию 0). Без Vault плагин работает как обычно.

Хранение: `plugins/VitalisRegions/regions.yml`, сейв при выключении. Поиск региона идёт по индексу мира — защита не лагает даже при сотнях регионов.

## Тесты

16 юнит-тестов (геометрия регионов, тексты): `.\gradlew.bat test`.

## Зависимости

- Ничего обязательного нет
- По желанию: Vault + экономика (цена создания), Essentials, WorldGuard (мирно сосуществуем, защиты складываются)

## Установка

1. Положить `VitalisRegions-X.X.X.jar` в `plugins/`
2. Перезапустить сервер
3. В консоли: `VitalisRegions enabled, regions: 0`
4. В игре: `/area wand`, выделить, `/area create home`, настроить через `/area info home`

## Сборка

```bat
.\gradlew.bat build --no-daemon
```

Нужны Java 21, Paper API `1.21.11-R0.1-SNAPSHOT`, VaultAPI (подтянутся сами).
